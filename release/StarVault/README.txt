# 星穹智识 StarVault v1.0.0

二次元风格的个人知识管理工具。

## 使用方法

1. 确保已安装 Node.js (v18+)
2. 双击运行 「启动星穹智识.bat」
3. 浏览器将自动打开 http://localhost:3001

## 数据存储

所有数据存储在 `starvault-data.json` 文件中。
可通过设置面板导出/导入数据备份。

## 快捷操作

- 创建卡片: 点击右下角 + 按钮
- 搜索知识: 顶部搜索框
- 切换主题/字体: 右上角设置图标
